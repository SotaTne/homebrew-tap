# SotaTne Homebrew Tap

Homebrew formulae for SotaTne projects.

## Install

```sh
brew tap SotaTne/tap
brew install typstlab
```

Or install directly:

```sh
brew install SotaTne/tap/typstlab
```

## Formulae

| Formula | Description |
| --- | --- |
| `typstlab` | A CLI tool for managing Typst writing projects. |

## Update

```sh
brew update
brew upgrade typstlab
```

## Uninstall

```sh
brew uninstall typstlab
brew untap SotaTne/tap
```

## Bottles

Pull requests are tested with `brew test-bot`. When the checks pass, applying the `pr-pull` label publishes bottles through the tap workflow.
